Política de Privacidade

Última atualização: 16 de maio de 2026

Visão Geral

Carteira PIX ("o App") é um gerenciador pessoal de chaves PIX e gerador de cobranças. Sua privacidade é importante para nós. Esta política explica como tratamos seus dados.

Coleta de Dados

O App não coleta, transmite ou compartilha dados pessoais com terceiros. Todos os dados inseridos (chaves PIX, cobranças, configurações) são armazenados exclusivamente no seu dispositivo.

Sincronização iCloud

Se você ativar a sincronização via iCloud, seus dados serão armazenados na sua conta privada do iCloud usando o serviço CloudKit da Apple. Esses dados são acessíveis apenas por você, em dispositivos conectados ao seu Apple ID. Não temos acesso aos seus dados do iCloud.

Análises e Rastreamento

O App não utiliza nenhum framework de análise, publicidade ou rastreamento. Nenhum dado de uso é coletado ou enviado a qualquer lugar.

Dados Biométricos

Se você ativar a autenticação biométrica (Face ID / Touch ID), o App utiliza o framework LocalAuthentication da Apple. Os dados biométricos são tratados inteiramente pelo sistema operacional e nunca são acessados ou armazenados pelo App.

Armazenamento de Dados

Todos os dados são armazenados localmente no seu dispositivo usando o framework SwiftData da Apple. Se a sincronização via iCloud estiver ativada, os dados também são armazenados no seu container privado do CloudKit. Você pode excluir seus dados a qualquer momento dentro do App ou nas Configurações do iOS.

Serviços de Terceiros

O App não integra com nenhum serviço, API ou SDK de terceiros.

Privacidade de Crianças

O App não coleta dados de crianças intencionalmente. Como nenhum dado pessoal é coletado de qualquer usuário, isso se aplica igualmente a todas as faixas etárias.

Alterações nesta Política

Podemos atualizar esta política periodicamente. As alterações serão refletidas nesta página com uma data atualizada.
