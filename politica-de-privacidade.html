Política de Privacidade

Última atualização: 30 de julho de 2026

Visão Geral

Carteira PIX ("o App") é um gerenciador pessoal de chaves PIX e gerador de cobranças. Sua privacidade é importante para nós. Esta política explica como tratamos seus dados.

Coleta de Dados

O App não coleta, transmite ou compartilha dados pessoais (como CPF, CNPJ, e-mail, telefone, valores de cobrança, chaves PIX ou payloads EMV) com terceiros. Todos os dados inseridos (chaves PIX, cobranças, configurações) são armazenados exclusivamente no seu dispositivo.

Análises de Uso (Firebase Analytics)

O App utiliza o Firebase Analytics (Google) para entender como os usuários interagem com o App e melhorar a experiência. Os dados coletados são:

  • Informações técnicas automáticas: modelo do dispositivo, versão do sistema operacional, versão do App, duração da sessão.
  • Eventos de uso: tipo de chave PIX criada (categoria, não o valor), categoria de cobrança (ex: "Pessoal" ou "Trabalho"), tema escolhido, preferência de biometria — todos sem conteúdo sensível.
  • Identificador do dispositivo: um identificador anônimo gerado pelo Firebase para distinguir usuários únicos.

O que NÃO é coletado: nenhum dado pessoal inserido no App (CPF, CNPJ, e-mail, telefone, nome do titular, valores de cobrança, chaves PIX, payloads EMV, nome do banco) é enviado ao Firebase ou a qualquer outro serviço.

Para mais informações, consulte a Política de Privacidade do Firebase e a Política de Privacidade do Google.

Dados Biométricos

Se você ativar a autenticação biométrica (Face ID / Touch ID), o App utiliza o framework LocalAuthentication da Apple. Os dados biométricos são tratados inteiramente pelo sistema operacional e nunca são acessados ou armazenados pelo App.

Armazenamento de Dados

Todos os dados são armazenados localmente no seu dispositivo usando o framework SwiftData da Apple. Você pode excluir seus dados a qualquer momento dentro do App ou nas Configurações do iOS.

Serviços de Terceiros

O App utiliza o Firebase Analytics, um serviço de análise fornecido pelo Google, para coletar dados anônimos de uso conforme descrito na seção "Análises de Uso". Nenhum outro serviço, API ou SDK de terceiros é utilizado. O App não utiliza frameworks de publicidade ou rastreamento.

Privacidade de Crianças

O App não coleta dados de crianças intencionalmente. Como nenhum dado pessoal é coletado de qualquer usuário, isso se aplica igualmente a todas as faixas etárias.

Alterações nesta Política

Podemos atualizar esta política periodicamente. As alterações serão refletidas nesta página com uma data atualizada.
